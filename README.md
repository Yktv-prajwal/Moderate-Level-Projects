# 1.Student Report Card Management System in Python

## Description
This Python program is a simple Student Report Card Management System that allows users to store and manage academic records for multiple students. The program collects each student's name, five subject names, and their corresponding marks. It then calculates the total marks, average score, and assigns a grade based on the average. Finally, it displays a detailed report card for every student.

## Features
• Stores details for multiple students.
• Accepts five subject names and marks for each student.
• Calculates total and average marks automatically.
• Assigns grades based on average performance.
• Displays a formatted report card.
• Beginner-friendly project demonstrating Python fundamentals.

## Concepts Used
• User input using `input()`
• Type casting with `int()`
• Lists and nested lists
• `for` loops
• Variables
• List methods (`append()`)
• Built-in functions (`sum()`, `round()`)
• Conditional statements (`if-elif-else`)
• Arithmetic operations
• Formatted output using `print()`

## Working
1. The user enters the number of students.
2. For each student, the program:
   - Accepts the student's name.
   - Accepts five subject names.
   - Accepts marks for each subject.
3. The program calculates:
   - Total marks.
   - Average marks.
   - Grade based on the average.
4. All student information is stored in a list.
5. After data entry is complete, the program displays a detailed report card for each student, including:
   - Student name.
   - Subject-wise marks.
   - Total marks.
   - Average marks.
   - Final grade.

## Grading Criteria
• Average ≥ 90 : A+
• Average ≥ 75 : A
• Average ≥ 60 : B
• Average ≥ 40 : C
• Average < 40 : Fail

## Learning Outcomes
This project helps beginners understand:
• Nested lists and data storage.
• Looping through complex data structures.
• Conditional logic for grading systems.
• Using built-in Python functions.
• Basic data processing and report generation.

## Project Objective
The main objective of this project is to automate the process of generating student report cards by calculating total marks, average scores, and grades while organizing and displaying student academic information efficiently.
